# Contributing to cbpipe

Thank you for your interest.

- **Report a bug or ask a question:** open an issue at https://github.com/kazutakahayashiyorosix/cooperation-behavior-pipeline/issues. Include the cbpipe version, Python version, the command you ran and the full error.
- **Propose a change:** open an issue first for anything larger than a small fix. Then send a pull request against `main`. Keep `pytest` green and add a test for new behavior.
- **Data:** never add real platform data, personal data, account IDs, e-mail addresses or credentials. Use the synthetic generator or public data only.
- **Style:** English comments and docstrings; functions small and documented.

The maintainer aims to reply to issues within two weeks.
